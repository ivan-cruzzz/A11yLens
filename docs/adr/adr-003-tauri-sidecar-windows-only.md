# ADR-003: Windows-приложение — Tauri 2 + CLI-движок как sidecar; только Windows

Дата: 2026-11-02. Статус: принято. Источник: spec R04–R04.3, manifest R04 («без линукса» — решение пользователя).

## Контекст

R04 требует «софт на ПК», работающий без Node и браузера на чистой Windows 10+. Пользователь ограничил платформу («без линукса»); сборка под macOS требует мака — ушла в документ идей (R07), не в сборку. Electron отвергли заранее: тяжёлый рантайм и второй UI-стек.

## Решение

`desktop/` на Tauri 2, единственный таргет — Windows; установщики NSIS + MSI с ярлыком. UI переиспользует React-компоненты веба. Сканирование — через CLI-движок, собранный в Node SEA-бинарник `a11ylens-engine.exe` (sidecar, скрипт `scripts/build-sidecar.mjs`): Tauri вызывает invoke-команду `run_engine(args)` и читает stdout команды `--json` — `{scan: ScanResult, native: NativeReport|null}`. Первый запуск: экран этики («проверяйте только свои сайты или с разрешения») и явное согласие на докачку Chromium (`check_browser`/`install_browser`). Резолв движка: env `A11YLENS_ENGINE` → рядом с exe → ресурс → dev-фолбэк `node src/cli/bin.mjs`. История сканов — файл в app data, не localStorage. Режимы интенсивности маппятся на флаги CLI: quick|normal|deep → `--mode` + `--max-pages 2|4|8` + `--timeout 45|90|180с`.

## Последствия

- Один движок, компактный дистрибутив и нативное окно вместо Electron-монстра; состояние (`AppState{ethicsAccepted, chromiumConsent, theme}`) в Tauri-сторадже, не в браузере.
- Цена: sidecar-протокол зафиксирован — любое новое поле отчёта проходит через контракт stdout `--json`; «продолжить после обрыва» (R04.3) реализовано повтором недосканированных страниц через `--max-pages=остаток`, потому что пер-страничного оффсета в CLI-контракте нет (механика описана в desktop/README.md); Chromium в комплект не входит — первый скан зависит от докачки, которая требует сети и согласия пользователя.
