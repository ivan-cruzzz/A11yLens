# 04 — Нативное Windows-приложение (Tauri)

**Требования:** R04
**Зависит от:** 03
**Зона:** `desktop/` (новая) · артефакты сборки
**Волна:** 3
**Ревью:** нет
**Модель:** сильная

## Что должно заработать

Нативное Windows-приложение A11yLens Desktop на Tauri 2: окно с вводом URL, прогрессом сканирования и полным отчётом (доступность + безопасность + нативные проверки), локальная история сканов. Сканирование — через движок как sidecar (CLI-бинарник). Первый запуск: экран «проверяйте только свои сайты или с разрешения» и согласие на докачку Chromium. Режимы быстро/обычно/глубоко. Обрыв сети — частичный отчёт с пометкой и продолжением. Установщик NSIS с ярлыком.

## Критерии приёмки

- [ ] окно приложения: ввод URL → прогресс → отчёт со всеми секциями (a11y + security + native); история сканов сохраняется между запусками локально
- [ ] сканирование идёт через sidecar-бинарник движка; UI не блокируется, прогресс виден по этапам
- [ ] первый запуск показывает экран этики («только свои сайты или с разрешения») и запрос на докачку Chromium; без согласия скан не запускается
- [ ] режимы быстро/обычно/глубоко меняют таймауты/паузы/лимиты (один конфиг с CLI `--mode`)
- [ ] обрыв сети на середине: частичный отчёт сохраняется с пометкой «неполный», повтор продолжает с прерванного места, а не с нуля
- [ ] сборка установщика проходит локально (Windows-таргет, NSIS/MSI), приложение запускается на чистой Windows 10+ без Node и браузеров
- [ ] в README проекта появляется раздел «Windows-приложение»: как собрать установщик самому
