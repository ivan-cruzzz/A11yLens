# 03 — Нативные проверки и CLI

**Требования:** R05, G01, A01
**Зависит от:** 01
**Зона:** `src/engine/native/` · `src/cli/` · `tests/native/` · `tests/cli/` · `package.json` (bin)
**Волна:** 2
**Ревью:** нет
**Модель:** обычная

## Что должно заработать

Пять нативных проверок в `src/engine/native/` (Node `tls`/`dns`/`net`, без браузера): TLS-аудит, топ-100 портов, поддомены через crt.sh, CVE библиотек через OSV, почтовые записи SPF/DKIM/DMARC — каждая с критичностью, рецептом и (для нативных) попаданием в отдельную секцию отчёта. Плюс инвентарь технологий страницы. И CLI `a11ylens scan <url>`: цветной отчёт в терминале (сводка, скоры, топ-находки, план исправления), флаги `--json/--csv/--security-only/--a11y-only/--max-pages/--timeout/--fail-under/--mode`, exit code по порогу.

## Из брифа, дословно

> «сделай софт на пк для более качественной проверки на возможную кибератаку и тд»
> Дополнение-рекомендации: «все пять смежных проверок: TLS-аудит (сертификат, протоколы, шифры), лёгкий скан топ-портов, поиск поддоменов (пассивный), CVE в найденных библиотеках через бесплатную OSV, почтовая безопасность домена (SPF/DKIM/DMARC)»
> «но сделай возможность проверки сайта через терминал»

## Критерии приёмки

- [ ] TLS-аудит: срок сертификата (≤30 дней — warning, истёк/самоподпис/имя не совпадает — high), TLS 1.0/1.1 — high, нет TLS — high; всё тестами на моках сокета
- [ ] скан портов: топ-100 параллельно, таймаут 1с на порт, завершение ≤30с; открытые опасные порты (21/23/135/139/445/3389 и др.) — находки с критичностью
- [ ] поддомены: crt.sh + DNS-резолв, без брутфорса; сеть в тестах замокана
- [ ] CVE: версия библиотеки со страницы → OSV → finding с CVE-id и ссылкой; при недоступности OSV — деградация с пометкой, не падение
- [ ] почта: SPF/DMARC/DKIM из DNS TXT; кеш запросов на время скана
- [ ] `npx a11ylens scan example.com` печатает читаемый отчёт в Windows-терминале; `--json` машиночитаем; `--fail-under 80` даёт exit code 1 при скорe < 80
- [ ] `--security-only`/`--a11y-only`/`--max-pages`/`--timeout` работают; недоступный сайт — понятная ошибка с причиной и exit code 2
- [ ] при отсутствии Playwright-браузера CLI печатает одну подсказку с готовой командой установки
- [ ] `npm test` зелёный (native и cli покрыты), `npm run build` проходит
