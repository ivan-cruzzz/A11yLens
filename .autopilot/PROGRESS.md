# A11yLens — что осталось

Последняя сборка: `.autopilot/2026-11-02-a11ylens-upgrade--wip/` — качество сканера, нативные проверки (TLS/порты/поддомены/CVE/почта), CLI `a11ylens scan`, Windows-приложение (Tauri), темы и разбор проблем без ИИ; 229 тестов, сборка зелёная, слепая приёмка из чистого клона прошла.

## Договорились — не пересматривать

- Реальный ИИ-провайдер не подключаем вообще — разбор только словарями и эвристиками («его отмена»)
- Десктоп только под Windows («без линукса»); macOS/Linux — идея в `docs/IDEAS.md`
- «Проверка на кибератаку» = поиск слабых мест, не детект уже идущих атак
- HIBP и любые платные API — нет; внешние вызовы только бесплатные (OSV, crt.sh)
- Новые идеи — документом `docs/IDEAS.md`, не разделом приложения

## Не доделано

- TLS-аудит без проверки шифров (в принятой рекомендации было «сертификат, протоколы, шифры») — решает пользователь: добавить или снять (R05)
- CLI `--security-only` не отключает браузерную axe-часть — нужен опциональный пропуск в runScan
- Полный браузерный скан (веб/CLI/self-scan) в этой машине не проверялся живьём: Playwright-браузеры снесены в ходе сборки, CDN гео-блок — после `npx playwright install chromium` должно работать, но прогон не подтверждён

## Известные баги

- `npm run scan:self` без установленных браузеров падает жёстко (beforeAll бросает), в отличие от theme-тестов с graceful skip — `tests/`, vitest.self.config
- MSI-сборка desktop падает при параллельном прогоне с NSIS (патчят один exe); повтор `npm run tauri build -- --bundles msi` проходит
- CSV: строка summary — 6 ячеек при заголовке из 5 колонок — `src/cli/csv.ts`
- withFetchRecorder при перемежающихся параллельных сканах оставляет безвредную обёртку на globalThis.fetch до конца процесса — `src/engine/scan.ts`
